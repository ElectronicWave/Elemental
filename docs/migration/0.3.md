# Migrating from 0.2 to 0.3

0.3 makes launcher futures usable from runtimes that require `Send`, such as
`tokio::spawn`, `axum`, and TUI kernels.

## Launcher and drivers

| 0.2 | 0.3 |
| --- | --- |
| `Driver` used `#[async_trait(?Send)]` | `Driver` uses `#[async_trait]` and requires `Send + Sync` |
| Custom drivers could store non-`Send` state | Custom drivers and their sources must be `Send + Sync` |
| `Launcher` async methods returned `!Send` futures | `Launcher` async methods return `Send` futures |

Third-party `Driver` implementors only need to add `Send + Sync` bounds where
their state requires them; the trait methods themselves do not change.
